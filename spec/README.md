# Proposed Arcxiom specification

The [single-file source and canonicalization profile](archyaml-v0.1-compat.md) and [ArchIR structural schema](archir-v0.1.schema.json) describe the implemented experimental edition. The [shared corpus](../tests/conformance/0.1-draft/cases.json) exercises the supported intersection of the Rust and Python implementations.

Candidate specification topics:

1. Lexical and YAML source profile
2. Identifiers, namespaces, imports and type/profile registries
3. ArchIR nodes, relationships, attributes, units and references
4. Requirements, constraints, decisions, and evidence
5. Versioning, canonical interchange and conformance
6. View projections and drawing-set interchange
7. Standards profile editions, permissions and declared compliance scope

Nothing here is yet normative or a conformance claim.

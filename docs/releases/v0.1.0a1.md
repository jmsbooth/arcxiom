# Arcxiom v0.1.0a1 — experimental alpha

Arcxiom's first runnable Architecture-as-Code prototype, released as an **experimental open-source alpha**, not a production architecture authority or finalized industry specification.

## Included

- A Python 3.11+ `arcxiom` CLI with strict `.arch.yaml` prototype parsing, typed architectural nodes and directed relationships.
- `validate`, `query`, deterministic ArchIR JSON `export`, conservative `diff`/guardrail checks, and a standards-neutral vector PDF schematic exporter.
- An independent Rust 1.85 ArchIR JSON structure/digest verifier for exported models (not a Rust YAML compiler).
- An original emergency-response example, draft schema, architecture decision records, tests, and documented security boundaries.

## Install

Download the attached `arcxiom_prototype-0.1.0a1-*.whl` asset and run `python3.13 -m pip install ./arcxiom_prototype-0.1.0a1-*.whl` in a virtual environment, or install directly from source. The wheel and `SHA256SUMS` are included as release assets; use `sha256sum -c SHA256SUMS` on Linux or `shasum -a 256` on macOS to verify the wheel hash.

```bash
arcxiom validate examples/emergency-response.arch.yaml
arcxiom export examples/emergency-response.arch.yaml --output archir.json
arcxiom render examples/emergency-response.arch.yaml --format pdf --output example.pdf
```

## Known limitations

- The draft language, type registry, canonicalization and ArchIR are **pre-standard**, and source assertions are **not independently verified telemetry**.
- Guardrail deltas use caller-provided, **unauthenticated** baselines. They are not access-control, policy admission, or approved-change authorization.
- Rust validates exported ArchIR JSON only. Numeric compatibility is limited to integral JSON values in [-2^63, 2^64-1], with floats rejected pending a formal canonicalization profile.
- Generic PDF drawings are **schematic, not to scale**. No ISO 128, ISO 5457, ISO 7200, BS EN ISO 19650, NCS/UDS, PDF/A, PDF/UA or construction drawing conformance is claimed.
- The prototype is not a hardened multi-tenant parser, runtime security product, trusted provenance service or CAD implementation.
- This release does not distribute any restricted standards text, symbols, templates or code tables.

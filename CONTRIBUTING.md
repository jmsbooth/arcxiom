# Contributing to Arcxiom

The project is at the design and licensing stage. Issues and RFCs should describe user problems, semantic requirements, examples, failure behavior, and interoperability trade-offs.

Do not contribute text, diagrams, rule tables, symbols, proprietary extracts, or fixtures from restricted standards unless you can demonstrate that redistribution and software/AI integration are authorized.

Before accepting code contributions, maintainers will select and publish an explicit open-source license, a contribution policy, and a public specification-governance process.
